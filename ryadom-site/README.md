# Рядом

Готовый адаптивный одностраничный сайт будущего сообщества взаимной эмоциональной поддержки. HTML, CSS и JavaScript без сторонних библиотек, внешних шрифтов, аналитики, форм, cookies и платёжных функций. Иллюстрация SVG входит в проект.

## Посмотреть сайт

Самый простой способ — открыть `dist/index.html` в браузере: страница работает и без сервера.

Для локального сервера нужен Node.js 18 или новее. Откройте терминал в папке проекта и выполните:

```sh
node server.mjs
```

Откройте http://127.0.0.1:4173. Устанавливать зависимости не требуется. Остановка сервера — Ctrl+C. Если доступен npm, также можно использовать `npm start` и `npm run check`.

## Добавить группу ВКонтакте

Откройте `dist/config.js`. Замените пустую строку у `vkUrl` на реальную HTTPS-ссылку вашей группы, сохраните файл и обновите страницу. Допускаются адреса на vk.com и vk.ru.

Пока ссылка пустая или некорректная, верхняя кнопка «Группа ВК · скоро» ведёт только к объяснению на этой же странице. Нижняя кнопка неактивна. Никакой выдуманной группы нет. После добавления корректного адреса обе кнопки открывают группу в новой вкладке, а подписи о ссылке меняются автоматически. Проверка адреса не подтверждает существование группы — откройте вашу реальную ссылку перед публикацией.

Тексты остальных разделов отражают подготовку к запуску. Когда группа действительно заработает, обновите будущее время в `dist/index.html`, описание страницы и статус команды. Не заявляйте о наличии специалистов, модерации 24/7 или конфиденциальности, если этого нет.

## Развёртывание

Это статический сайт. Разместите **содержимое папки `dist`** на любом статическом HTTPS-хостинге. Корневой файл — `index.html`; команда сборки и установка пакетов не нужны. Если панель хостинга требует каталог публикации, укажите `dist`.

Для GitHub Pages поместите содержимое `dist` в корень публикуемой ветки и включите Pages для этой ветки. Относительные пути позволяют разместить сайт и в подпапке. Для хостинга с загрузкой архива отправьте файлы из `dist`, без внешней папки.

В `.openai/hosting.json` хранится идентификатор отдельного сайта в Sites. Он относится к этому проекту; не используйте его для создания другого сайта. Локальный `server.mjs` нужен только для просмотра, а не для размещения в интернете.

## Файлы

- `dist/index.html` — содержание, разделы и раскрывающиеся правила.
- `dist/styles.css` — оформление и адаптация к ширине экрана.
- `dist/config.js` — единственное место для ссылки ВК.
- `dist/app.js` — безопасное переключение кнопок ВК.
- `dist/together.svg`, `dist/favicon.svg` — локальные иллюстрация и знак.
- `server.mjs` — локальный сервер без зависимостей.

## Доступность и границы

Навигация с клавиатуры, видимый фокус, ссылка пропуска навигации, семантические заголовки, нативные раскрывающиеся разделы, описание иллюстрации и поддержка уменьшения движения. Основной контент и правила доступны без JavaScript.

Сайт не принимает сообщения и не хранит личные истории. При переходе во ВКонтакте действуют правила и настройки этой платформы. Сообщество состоит из добровольцев, не является профессиональной службой, терапией или зарегистрированным фондом. Ответ и его скорость не гарантируются. В кризисном блоке указан 112 для РФ; источник — МЧС России, ссылка есть на странице. Это экстренный номер, не линия психологической поддержки.
